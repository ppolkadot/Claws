# Claws 1.0.9

Windows build prepared on `improve/phase-0-safety-net` ([pull request 1](https://github.com/ppolkadot/Claws/pull/1)). **Not published**: the latest published release is 1.0.8. Installation/upgrade has not been exercised, and nothing below was run in the native app.

## Changes

- **Download speed:** processing no longer holds a transfer slot (`max_processing`, default 2), so up to 5 jobs can run at once with the defaults. Optional per-download speed limit (a limited start fetches one fragment). The fragment default stays at 8; `formats=dashy` and aria2c were not built because the benchmark gate was not met ([real-source benchmark](../performance/real-source-benchmark.md)).
- **Setup:** Claws installs Deno itself, checksum verified, and a first-run panel installs yt-dlp, ffmpeg and Deno from one button. Nothing is downloaded until it is pressed.
- **Queue and Library:** Pause All, Resume All, Retry Failed, Move to Top, a summary line, the processing step, error details with Copy, taskbar progress, finish notifications (on by default; new dependency `tauri-plugin-notification`), Library sorting and filtering, remembered choices.
- **Motion:** page-only navigation, a transform-based sidebar, gliding Library cards, a lookup skeleton, one easing for leaving rows ([motion polish](../performance/motion-polish.md)).
- **Features:** chapters embedded with the metadata pass, optional SponsorBlock for YouTube (contacts `sponsor.ajay.app` through yt-dlp, only when turned on), playlist folders.
- The Download view is split into modules with no behavior change. Settings schema stays 2 and queue schema 3; every new field is defaulted.

## Validation and limits

468 Rust tests passed (3 opt-in live tests ignored), 316 frontend tests passed, warning-denying feature-enabled Clippy and the production build passed. CI passed on the branch head before the version bump and comment cleanup.

Not verified: real merges with the new slots, the speed limit on a real site, first-run setup on a clean profile, notifications, taskbar progress, SponsorBlock, chapters and playlist folders on real downloads, and how the motion looks. `scripts/test_font_metrics.py` cannot run on the build PC (Python has no `brotli` module); it fails the same way without these changes. The installer is unsigned.
