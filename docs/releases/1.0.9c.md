# Claws 1.0.9c

Windows x64 build on `main`. The installer filename uses the `1.0.9c` nickname. The installer and bundled app both report Windows FileVersion and ProductVersion `1.0.9`; the sidebar shows `Claws 1.0.9c`.

- [Windows installer](../../installers/Claws_1.0.9c_x64-setup.exe) · [SHA-256 checksum](../../installers/Claws_1.0.9c_x64-setup.exe.sha256)
- **Install SteamCMD** in the Wallpaper Engine panel and in Settings downloads Valve's SteamCMD into Claws' tools folder, accepts it only with Valve's Authenticode signature, and runs it once so it updates itself. A copy you already have can still be chosen. See the [setup guide](../../README.md#wallpaper-engine).
- The Steam account name fills in from this PC: SteamCMD's own sign-ins first, then the Steam client's most recent and remembered accounts. Nothing leaves the PC.
- Windows' own minimize, maximize and close buttons no longer exist behind the top-right corner. The window drops the system menu style, so Alt+Space goes; snapping, Win+Arrow, minimize and maximize still work.
- The sidebar shows the installed Claws build beside the tool dot.

## Build and verification

Built with `npm run tauri build -- --bundles nsis` from branch `steamcmd-auto-install` on top of `0d8a966`.

- The installer is 3,204,445 bytes. SHA-256 is `5842809788e1b4464b6ba46b979ec9692942f9df19a573fa9fa48390d535e6a1`. Authenticode reports `NotSigned`.
- 7-Zip verified the NSIS archive and extracted `claws.exe`. Its SHA-256 is `8124950da276ebb0e9fd1e3cbbdf710d4f704b0e7ff784470a23bf474adeb31d`. The unpackaged production executable hashes to `d59382435830ab3e2bc56e0e05334d1b41281cd38169cbd037d6de751bed34d0`. Only the three bytes of Tauri's NSIS bundle marker differ.
- 321 frontend tests passed (logic 183, queue 30, motion 65, Spotify 43), with seven font bundle tests. 488 Rust tests passed with three opt-in tests ignored, and the two new SteamCMD unpacking tests passed, one of them on Valve's real `steamcmd.zip`. Clippy with warnings denied and the production build passed.
- Not yet checked in the native app: the window-button change, a full SteamCMD install with its first update, account detection on a PC with Steam, a SteamCMD download with an account that owns Wallpaper Engine, the Steam library source, and installation or upgrade.
