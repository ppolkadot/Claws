# Claws 1.0.9a

Windows x64 build on `main`. The installer filename uses the `1.0.9a` nickname. The installer and bundled app both report Windows FileVersion and ProductVersion `1.0.9`.

- [Windows installer](../../installers/Claws_1.0.9a_x64-setup.exe) · [SHA-256 checksum](../../installers/Claws_1.0.9a_x64-setup.exe.sha256)
- Wallpaper Engine Workshop links open a download panel. Claws uses SteamCMD with the owning Steam account and saves the full project as a ZIP. See the [setup guide](../../README.md#wallpaper-engine).
- The [UI cleanup](../UNSLOP_UI_REVIEW.md) simplifies copy, icons and spacing, labels the filename input, and removes the Library tile lift and zoom.
