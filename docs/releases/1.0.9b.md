# Claws 1.0.9b

Windows x64 build on `main`. The installer filename uses the `1.0.9b` nickname. The installer and bundled app both report Windows FileVersion and ProductVersion `1.0.9`.

- [Windows installer](../../installers/Claws_1.0.9b_x64-setup.exe) · [SHA-256 checksum](../../installers/Claws_1.0.9b_x64-setup.exe.sha256)
- Wallpaper Engine gains a preview card, a Steam library source that needs no sign-in in Claws, and SteamCMD with a saved, Valve-signature-checked location and account. Exports show progress with Cancel, name the ZIP after the title and check free space. Collections are refused and required items are flagged. See the [setup guide](../../README.md#wallpaper-engine).
- The [UI cleanup](../UNSLOP_UI_REVIEW.md) fixes site names, English dates and audio counts, shortens hints and tooltips, and aligns Queue rows and preview edges.
- The toolbar centres on the traffic lights' line. The Queue summary shows at most three facts, and only paused and failed counts when nothing is transferring.
- The Drag file control is an icon button. A Back control and the Esc key return link details, wallpaper items, Spotify matches, lists and errors to the empty Download page.

Built with `npm run tauri build -- --bundles nsis` from branch `t3/wallpaper-engine-unslop`, at commit `6c6e876` plus the uncommitted 1.0.9b fixes.

- 321 frontend tests passed (logic 183, queue 30, motion 65, Spotify 43), with seven font bundle tests and 486 Rust tests. Three opt-in Rust tests were ignored. The production build and Clippy with warnings denied also passed.
