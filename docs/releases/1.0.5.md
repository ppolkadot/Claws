# Claws 1.0.5

This release improves download reliability, recovery and responsiveness for large queues.

- Downloads use separate work folders. Cancellation cleans unfinished files while preserving published media, and retries keep their original destination and settings.
- Interrupted publication and Library saves can recover without downloading the file again. Missing or replaced videos are detected; renamed or deleted subtitle sidecars no longer block Try Again.
- Startup verifies recoverable completed downloads in the background and keeps the interface synchronized with recovery.
- Queue saves run outside download readers, playlist additions are batched, and large queues render in smaller batches.
- Progress accounts for the bytes in both video and audio streams. Unknown sizes stay indeterminate, and processing is shown separately.
- Downloads retry transient failures with backoff, fail on missing fragments, and produce less progress output.
- Optional matching audio selection can avoid conversion when a suitable source exists. Fast Save skips requested metadata and subtitle embedding passes.
- Disk-space estimates account for simultaneous downloads and processing. Processing checks are best effort, rather than a guarantee that enough space will remain.
- Tool output has memory limits and clearer failure diagnostics. The bundled Salted Flutters Polaris font includes the character-spacing correction.

Validation: 134 backend tests, 11 queue tests, two font tests, a clean dependency install, the frontend build, feature-enabled Clippy, and a production NSIS build. The installer payload and uploaded checksums are verified during publication.

Known limits: this release does not establish a fix for low download speed on the affected real source. Parallel HTTP acceleration and combined processing remain future work. A fresh Windows installation, an upgrade from an installed 1.0.4, and large-file startup on a USB drive have not been tested. Releases are unsigned. The font is bundled; yt-dlp is installed on first launch, and FFmpeg is needed for merging and conversion.
