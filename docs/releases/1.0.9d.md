- Updated SteamCMD executables signed by Valve Corp. now pass publisher validation. Claws still requires Windows to verify the signature.
- Video wallpaper projects offer MP4, GIF or ZIP. MP4 keeps audio when present. GIF is silent and loops at 15 fps. Both use the source resolution, with odd dimensions rounded down by one pixel. ZIP preserves the full project and remains the option for scene, web and application wallpapers. See the [format guide](../../README.md#wallpaper-engine-formats).
