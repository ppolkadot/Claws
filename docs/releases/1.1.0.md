# Claws 1.1.0 (release candidate)

This release adds batch, editorial and text workflows and a restrained motion pass to the Windows downloader. **It is not published**: until it is, the published release remains 1.0.5. Nothing below has been exercised against a real site or in a real editor; see "Known limits".

## New

- **Paste many links.** One link per line, up to 500. Lookups run three at a time with a status per row; a failed link can be retried without losing the rest. Nothing starts until you press Download, and links already queued are reported, not added twice.
- **Size and free-space preview.** Shows the expected download size and, separately, the free space needed while the download works. It is computed from the same streams the download will use. Unknown sizes are shown as unknown, never as zero. Playlists and batches estimate only when you ask, for at most 200 selected items. The check made when a download starts is unchanged.
- **Resolutions the source really offers, up to 8K.** The quality choices come from the source's formats, with exact dimensions and a 4K, 5K, 6K or 8K label only when both sides justify it. Portrait video is handled by its shorter side. Nothing is upscaled.
- **Compatible or Original.** Compatible prefers H.264/AAC in MP4 when the site offers them (unchanged behaviour). Original keeps the site's best streams without re-encoding, as MP4 or, when MP4 cannot hold them, MKV. Remuxing does not repair a codec an editor cannot open.
- **Transcripts.** Save one caption track as TXT, TXT with timestamps, SRT or VTT without downloading the video. Human and automatic captions are listed separately; machine-translated automatic tracks are not offered. This uses the site's captions only: no speech recognition, and automatic captions can contain errors.
- **Drag into an editor.** A *Drag file* handle on finished downloads starts a real copy-only Windows file drag. The Library file is never moved. Press Enter on the handle to show the file in its folder.
- **Motion.** Link lookup settles into its preview; the Video / Audio / Transcript control slides; progress glides forward and snaps on any state change; removed queue rows collapse in place; a finished download gets a short check. Large batches, Clear Finished, hidden windows and Reduce motion do not animate.

## Changed and fixed

- The probe cache has a 256 MB budget, and a download holds its cache file until yt-dlp exits, so cleanup can no longer delete a file a download is about to read.
- The bundled-font checks now reject orphaned or legacy packaged fonts and run correctly through junctions or symlinks; the Settings font row updates once the font finishes loading.
- The indeterminate progress sheen animates with transform instead of layout; keyboard focus now survives a queue row changing status; a removed row no longer jumps to the end of the list while collapsing.
- Native drag refuses locations the `drag` crate would crash on (paths over 260 characters, reserved names, files on a network share) with a clear message, and no longer rejects OneDrive cloud-file placeholders.

## Compatibility

- Queue file schema is now 3. A 1.0.5 or earlier queue loads, with every job Compatible. **Downgrading is not supported**: 1.0.5 sets a schema-3 queue aside rather than reading it.
- New options (`videoPreset`, `transcriptFormat`) and probe fields are optional, so older saved jobs, history and cached links still load. The editing preset is not available and is rejected.

## Validation

227 backend tests, 11 queue tests, 7 font tests, 69 frontend logic tests, 37 motion tests, 2 Python font tests, a clean `npm ci`, the frontend build, feature-enabled Clippy with warnings denied, and a production NSIS build. Media tests run the installed yt-dlp and ffmpeg offline against synthetic clips and made-up metadata, checking Original output with ffprobe and packet hashes. Motion was measured in headless Edge against the dev mock with 500 queued rows and 8 active transfers: no long tasks while adding rows or during progress.

## Known limits

- **No real-site test.** Behaviour on real sites (caption shapes, 6K/8K and HDR formats, signed links) is unverified.
- **No editor test.** Dragging into Explorer or an editor, and whether an editor imports an Original MKV or any given codec, has not been tested; "dropped" means only that the mouse button was released, because the drag crate discards the receiver's result. A manual checklist is in `docs/CURRENT_DEVELOPMENT_STATUS.md`.
- **Drag limits.** Library files with paths over 260 characters or on a network share cannot be dragged (Show in folder still works); a receiver that never finishes a drag freezes Claws' window until it does (downloads continue), an upstream `drag` issue. Mouse only; Windows 10 is untested.
- **Install and upgrade untested.** A fresh install and an upgrade from 1.0.5 have not been run.
- **Speed.** This release does not establish a fix for slow downloads from the affected source; no speed claim is made.
- **Not included.** Clip sections (planned for a future version), ProRes and editing presets, replay metadata, speech recognition, vocal removal and macOS.
- Releases are unsigned. yt-dlp is installed on first launch, and FFmpeg is needed for merging, conversion, and converting some caption formats.
