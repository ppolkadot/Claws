# Claws 1.0.8

Local Windows build on `codex/release-1.0.8`, based on the reviewed Spotify matching branch. This build has not been published or installed by the assistant.

## Changes

- Paste one Spotify track link, review up to five YouTube recordings, choose a match explicitly and save audio through the existing format/options/queue pipeline. The actual file is YouTube audio; the recording may differ from Spotify. Queue and Library retain source attribution.
- Public Spotify metadata requires no account or developer credentials. Missing metadata supports an editable search; typed input/short-link failures show the appropriate recovery action. Album/playlist matching remains unsupported.
- Better collaboration/channel ranking, bounded Unicode search queries and Library search by Spotify title/artist. Keyboard composition keeps its input node; duplicate searches and stale replies are suppressed.
- Fixed interrupted lookup recovery, stale Retry actions, preconfirmation width, nested action alignment, empty-host spacing, focus after recovery, and duplicate no-results text.
- Small final polish: keyboard activation of **Use this match** advances focus to **Download** after audio verification; short-link recovery instructions appear once.
- Includes 1.0.7's Unicode finished-path fix and earlier download/publication protections.

## Validation and limits

Release checks and installer provenance are recorded below after the build. The Spotify verification history, including earlier live metadata/search and 12 native format/Fast Save saves, is in [the verification report](../spotify-track-matching-verification.md).

No real `spotify.link` share was tested live. Real OS IME/WebView2 acceptance, installation/upgrade and audible playback remain unverified; synthetic mounted Edge tests and native file/codec checks are separate evidence. The installer is unsigned. No remote release, tag, push or installation is part of this local build.
